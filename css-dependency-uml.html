CSS 의존성 — UML 클래스 다이어그램

같은 데이터를 UML 표기로. 각 HTML/CSS 파일 = 클래스, 점선 화살표 = 의존성(Dependency)

«stereotype» = 파일 종류(page/stylesheet) = 의존성(«import») 속성 구획 = 그 파일이 실제로 갖는 하위 항목(선택자·참조 파일)

Foundation Classes

«stylesheet» tokens.css
  • (색상 · 간격 · 타이포 변수)
«stylesheet» base.css
  • (리셋 · 접근성 기본값)
«stylesheet» components.css
  • - Card / Panel
  • - Skeleton
  • - Nav Item
  • - Button
  • - Chip / Badge
  • - Avatar
  • - Search Field
  • - Theme Toggle
  • - Date Picker
  • - KPI 블록
