레이어팝업 검증 하네스

페이지 안에 이미 있는 [data-pop] 영역을 숨겼다 보이게 합니다. 동작은 data-pop* 속성이, 생김새는 클래스가 담당합니다. 항목마다 확인할 것을 적어 두었으니 눌러 보면서 그대로 동작하는지 보세요.

사용법 한눈에

  1. 1. 파일 연결 
    <link rel="stylesheet" href="assets/css/popup.css" />
<script src="assets/js/popup.js"></script>
  2. 2. 팝업 영역 작성 (hidden 상태로 페이지 안에 둔다) 
    <div class="layerpopup" data-pop="cart" hidden>
  <div class="lp__panel" data-pop-panel>
    <h2 class="lp__title" data-pop-label>장바구니</h2>
    <button type="button" data-pop-close>닫기</button>
  </div>
</div>
  3. 3. 여는 쪽 (둘 중 편한 방식) 
    <button type="button" data-pop-open="cart">장바구니</button>

Popup.open("cart");   // 스크립트에서
속성붙이는 곳값 (기본값 굵게)
data-pop팝업 영역팝업 이름 (필수)
data-pop-panel안쪽 박스필수
data-pop-open여는 버튼팝업 이름
data-pop-close닫는 버튼값 없음 = 자기 팝업, 이름 = 그 팝업
data-pop-label제목스크린리더용 이름 연결
data-pop-type팝업 영역layer · full · drawer
data-pop-dim팝업 영역 · 버튼true · false · static
data-pop-size팝업 영역 · 버튼sm · md · lg (선언했을 때만 폭 제한)
data-pop-origin팝업 영역 · 버튼center · trigger
data-pop-sheet팝업 영역 · 버튼mobile · always
data-pop-side드로어left · right
data-pop-drawer드로어overlay · float · push · squeeze
data-pop-esc팝업 영역 · 버튼true · false
data-pop-scroll팝업 영역 · 버튼배경 스크롤 잠금. 딤이 false면 false, 아니면 true
data-pop-push-target본문 감싸개push · squeeze 가 밀어낼 요소 (body 제외)

옵션 우선순위는 Popup.open() 인수 > 여는 버튼 > 팝업 영역 > 기본값입니다. 팝업이 자기 기본값을 들고 있게 하고, 호출부는 예외만 덮어쓰세요. 아래 항목마다 사용법 보기를 펼치면 그 기능의 코드가 있습니다. 전체 레퍼런스는 사용법 가이드를 보세요.

01

기본 (마크업으로 열기)

버튼의 data-pop-open="basic"이 data-pop="basic" 영역을 엽니다. 확인할 것:

  • 확대·페이드 애니메이션이 보인다 (툭 나타나면 안 됨)
  • 닫기 버튼 · 우상단 X · 딤 클릭 · Esc 네 가지로 모두 닫힌다
  • 입력칸의 글자를 드래그하다가 딤에서 손을 떼도 닫히지 않는다
  • 열려 있는 동안 배경이 스크롤되지 않고, 닫으면 보던 위치 그대로다 (아래쪽 섹션에서 열어 보세요)
사용법 보기 
<!-- 여는 버튼 -->
<button type="button" data-pop-open="basic">기본 팝업 열기</button>

<!-- 팝업 영역: 페이지 어디에 써도 된다 -->
<div class="layerpopup" data-pop="basic" data-pop-size="md" hidden>
  <div class="lp__panel" data-pop-panel>
    <h2 class="lp__title" data-pop-label>제목</h2>
    <p>내용</p>
    <button type="button" data-pop-close>닫기</button>
  </div>
</div>

필수는 data-pop과 data-pop-panel 두 개입니다. 열 때 <body> 끝으로 옮겨졌다가 닫으면 제자리로 돌아오므로, 조상에 transform이나 overflow:hidden이 있어도 잘리지 않습니다.

02

딤 옵션

딤 있음(true)은 기본값이라 01과 같습니다. 여기서는 나머지 두 가지만 봅니다.

  • false: 딤이 없고, 팝업이 떠 있어도 뒤 페이지를 스크롤·클릭할 수 있다. Tab도 팝업에 갇히지 않는다
  • static: 딤이 있지만 딤을 눌러도 닫히지 않는다 (Esc와 버튼으로만 닫힘)
사용법 보기 
<!-- 딤 없음(비모달): 뒤 페이지를 쓸 수 있고 스크롤·Tab도 잠기지 않는다 -->
<div class="layerpopup" data-pop="notice" data-pop-dim="false" hidden>…</div>

<!-- 딤 있음, 딤을 눌러도 안 닫힘 (필수 동의) -->
<div class="layerpopup" data-pop="consent" data-pop-dim="static" hidden>…</div>

<!-- Esc로도 못 닫게 -->
<div class="layerpopup" data-pop="consent" data-pop-dim="static" data-pop-esc="false" hidden>…</div>

<!-- 딤은 두고 배경 스크롤만 풀기 -->
<div class="layerpopup" data-pop="x" data-pop-scroll="false" hidden>…</div>

dim과 scroll은 서로 독립된 옵션입니다. 다만 딤이 false면 scroll의 기본값도 false가 됩니다.

03

함수로 열기 · 결과 받기

버튼 없이 스크립트에서 Popup.open("confirm")으로 엽니다. 팝업 안의 버튼은 Popup.close("confirm", { confirmed: true })처럼 닫으면서 값을 넘기고, 부른 쪽은 pop:close 이벤트의 e.detail로 받습니다. 특별한 옵션이 아니라 닫을 때 두 번째 인수를 주는 것뿐입니다.

결과: 아직 선택하지 않음
사용법 보기 
// 열기
Popup.open("confirm");

// 이 호출에서만 옵션 덮어쓰기
Popup.open("confirm", { dim: "static", size: "sm" });

// 팝업 안의 버튼: 값을 실어서 닫기
Popup.close("confirm", { confirmed: true });

// 부른 쪽: 닫힐 때 값 받기
document.addEventListener("pop:close", function (e) {
  if (e.target.dataset.pop !== "confirm") return;
  if (e.detail && e.detail.confirmed) cancelOrder();
});

// 그 밖의 함수
Popup.close();               // 맨 위 팝업 닫기
Popup.closeAll();            // 중첩된 것까지 전부
Popup.isOpen("confirm");     // true | false
Popup.toggle("confirm");     // 열려 있으면 닫고, 닫혀 있으면 열기

조건에 따라 띄울 때나 통신 결과를 받은 뒤에 쓰면 됩니다. pop:open 이벤트도 같은 방식으로 받습니다.

04

중첩 (2차 팝업)

  • 1차 안에서 2차를 열면 2차가 위에 쌓인다
  • Esc 한 번에 2차만 닫히고 1차는 남는다
  • 2차가 떠 있는 동안 1차의 버튼은 눌리지 않는다
사용법 보기 
<!-- 설정할 것이 없다. 팝업 안에서 평소처럼 다른 팝업을 열면 된다 -->
<div class="layerpopup" data-pop="nest-1" hidden>
  <div class="lp__panel" data-pop-panel>
    <button type="button" data-pop-close>닫기</button>
    <button type="button" data-pop-open="nest-2">2차 팝업 열기</button>
  </div>
</div>

Esc는 맨 위 팝업만 닫고, 아래 팝업은 inert가 걸려 눌리지 않습니다. 배경 스크롤은 전부 닫힌 뒤에 풀립니다.

05

전체화면 (type="full")

화면 전체를 덮지만 페이지 이동이 아니라 레이어입니다. 닫으면 뒤 페이지가 그대로 있습니다. 모바일에서 주소창이 생기거나 사라져도 아래가 잘리지 않아야 합니다.

사용법 보기 
<!-- 전체화면 레이어: 뒤 페이지가 그대로 남아 있어 닫으면 바로 복귀한다 -->
<div class="layerpopup" data-pop="terms" data-pop-type="full" hidden>…</div>

<!-- 페이지를 아예 이동해야 하면 매니저를 쓰지 않고 그냥 링크 -->
<a href="/html/login/terms.html">약관 전문 보기</a>
06

클릭한 위치에서 열기 (origin="trigger")

두 버튼은 같은 팝업을 엽니다. 차이는 팝업이 커지기 시작하는 지점뿐입니다. 왼쪽은 화면 가운데에서, 오른쪽은 누른 버튼 자리에서 커지며 나옵니다. 버튼이 화면 끝에 있을수록 차이가 잘 보입니다.

사용법 보기 
<!-- 가운데에서 커지며 나옴 (기본) -->
<button type="button" data-pop-open="origin">기본</button>

<!-- 누른 버튼 자리에서 커지며 나옴 -->
<button type="button" data-pop-open="origin" data-pop-origin="trigger">이 버튼에서</button>

모션의 시작점만 바뀌고, 다 열린 뒤의 위치는 똑같이 가운데입니다. 전체화면·시트·사이드 패널에는 적용되지 않습니다.

07

바텀시트 (sheet)

  • mobile: 창 폭 640px 이하에서만 아래에서 올라온다. PC 폭에선 일반 팝업과 같다
  • always: 화면 폭과 상관없이 항상 아래에서 올라온다 (PC에서도 차이가 보임)
사용법 보기 
<!-- 640px 이하에서만 하단 시트 -->
<div class="layerpopup" data-pop="filter" data-pop-sheet="mobile" hidden>…</div>

<!-- 화면 폭과 상관없이 항상 하단 시트 -->
<div class="layerpopup" data-pop="filter" data-pop-sheet="always" hidden>…</div>

<!-- 여는 버튼에서 정할 수도 있다 -->
<button type="button" data-pop-open="filter" data-pop-sheet="always">필터</button>
08

키보드 · 포커스

마우스 없이 Tab과 Enter만으로 열고 닫아 보세요.

  • 열면 X 버튼이 아니라 첫 입력칸에 커서가 간다 (autofocus)
  • Tab·Shift+Tab이 팝업 안에서만 돈다
  • 입력칸에서 한글을 치는 도중 Esc를 눌러도 닫히지 않는다 (조합이 끝난 뒤 Esc로 닫힘)
  • 닫으면 원래 눌렀던 버튼으로 포커스가 돌아온다
사용법 보기 
<!-- 열 때 처음 포커스를 받는다. 없으면 닫기 버튼이 아닌 첫 요소로 간다 -->
<input type="text" autofocus />

<!-- 스크린리더가 읽는 팝업 이름 -->
<h2 data-pop-label>배송 정보 입력</h2>

<!-- 아이콘만 있는 버튼에는 aria-label 을 꼭 넣는다 -->
<button type="button" data-pop-close aria-label="닫기">…</button>

Tab은 팝업 안에서만 돌고, 닫으면 원래 눌렀던 버튼으로 포커스가 돌아옵니다. 한글 조합 중의 Esc는 무시합니다.

09

기존 페이지 · 기존 팝업 대응

  • 기존 팝업 편입: 자체 클래스로 디자인된 팝업(폭 600px, 각진 모서리, 상단 띠)에 data-pop·data-pop-panel만 붙였다. 원래 디자인이 그대로 나와야 한다
  • 갇힌 위치: transform·overflow:hidden이 걸린 상자 안에 작성된 팝업도 화면 전체를 덮는다
  • 늦게 들어온 버튼: 1초 뒤에 스크립트로 넣은 버튼(인클루드된 GNB/LNB 상황)도 따로 연결 없이 동작한다
늦게 들어올 버튼 대기 중…
transform: translateZ(0) · overflow: hidden · filter

상자를 벗어난 팝업

이 팝업의 마크업은 transform이 걸린 상자 안에 있습니다. 그대로 띄우면 상자 기준으로 갇히고 잘리지만, 매니저가 열 때 <body> 끝으로 옮겼다가 닫을 때 제자리로 돌려놓습니다.

사용법 보기 
<!-- 기존 팝업: 자기 클래스 디자인은 그대로 두고 속성 3개만 추가 -->
<div class="legacy-pop" data-pop="legacy" hidden>
  <div class="legacy-pop__inner" data-pop-panel>…</div>
</div>
<button type="button" data-pop-open="legacy">공지 열기</button>

// 기존 공통 함수를 어댑터로 바꿔 두면 호출부(onclick)를 안 고쳐도 된다
function openPop(id)  { Popup.open(id); }
function closePop(id) { Popup.close(id); }

기존 팝업 하나를 옮길 때 필요한 것은 data-pop · data-pop-panel · hidden뿐입니다. 이벤트는 document에서 한 번에 받으므로 인클루드로 나중에 들어오는 버튼도 따로 연결하지 않아도 됩니다.

10

사이드 패널 (type="drawer")

일곱 버튼이 모두 같은 팝업 하나를 엽니다. 방향(data-pop-side)과 나오는 방식(data-pop-drawer)을 여는 버튼 쪽에서 정하기 때문입니다.

  • 왼쪽 · 오른쪽: 가장자리에 붙어 본문 위를 덮는다 (딤 있음)
  • 플로팅: 가장자리에서 떨어져 둥근 모서리로 떠 있다
  • 밀어내기: 본문 전체가 패널 폭만큼 반대쪽으로 밀린다. 오른쪽 패널이면 본문이 왼쪽으로 밀린다. 딤이 없어 본문을 계속 쓸 수 있고, 같은 버튼을 다시 누르면 접힌다
  • 폭 줄이기: 본문이 밀려나지 않고 남은 폭에 맞춰 다시 배치된다. 창 폭 640px 이하에서는 밀어내기로 바뀐다
사용법 보기 
<!-- 햄버거 버튼: 열림 상태가 aria-expanded 에 자동 반영된다 -->
<button type="button" data-pop-open="side-menu" aria-expanded="false" aria-label="메뉴">…</button>

<div class="layerpopup" data-pop="side-menu"
     data-pop-type="drawer"
     data-pop-side="left"
     data-pop-drawer="overlay"
     hidden>
  <nav class="lp__panel" data-pop-panel aria-label="사이트 메뉴">…</nav>
</div>

<!-- data-pop-side   : left(기본) | right -->
<!-- data-pop-drawer : overlay(기본) | float | push | squeeze -->

<!-- push · squeeze 는 밀려날 본문 감싸개가 필요하다 (body 에는 붙이지 않는다) -->
<div class="wrap" data-pop-push-target>…본문…</div>

/* 패널 폭 */
:root { --pop-drawer-w: 320px; }

방향과 방식은 팝업 영역에 써도 되고, 여는 버튼에 써서 그 호출에서만 바꿀 수도 있습니다. push·squeeze는 본문을 계속 쓰는 용도라 딤과 스크롤 잠금이 기본으로 꺼져 있고, 같은 버튼을 다시 누르면 접힙니다.

이벤트 로그 0

기본 레이어팝업

닫기 버튼, 우상단 X, 딤 클릭, Esc 모두 닫힙니다.

딤 false

뒤 페이지를 그대로 쓸 수 있는 비모달 팝업입니다. 스크롤도 잠기지 않고, Tab도 이 안에 갇히지 않습니다. 딤이 없으면 이 셋이 기본으로 함께 풀립니다.

딤 static

딤을 눌러도 닫히지 않습니다. 필수 동의처럼 반드시 선택해야 하는 팝업에 씁니다.

주문을 취소할까요?

고른 결과가 버튼 옆과 아래 로그에 표시됩니다.

1차 팝업

여기서 2차를 열면 위에 쌓이고, 2차가 떠 있는 동안 이 버튼들은 눌리지 않습니다.

2차 팝업 (재확인)

Esc를 누르면 이것만 닫히고 1차는 남습니다.

전체화면 레이어

화면을 덮지만 이동이 아니라 레이어입니다. 뒤 페이지가 그대로 있어서 닫으면 바로 돌아가고, 입력하던 내용도 남아 있습니다.

페이지를 아예 이동해야 하는 "독립 페이지"는 이 매니저를 쓰지 않고 그냥 링크로 둡니다.

어디서 커졌나요?

origin="trigger"로 열었다면 누른 버튼 자리에서, 아니면 화면 가운데에서 커져 나왔습니다. 다 열린 뒤의 위치는 둘 다 가운데로 같습니다.

공지사항

이 팝업은 .legacy-pop 클래스로 이미 디자인되어 있던 팝업이라고 가정했습니다. 폭 600px, 각진 모서리, 상단 색 띠는 전부 기존 클래스가 정한 것이고, 바뀐 건 data-pop·data-pop-panel·hidden 세 개를 붙인 것뿐입니다.

매니저가 정하는 건 띄우는 방식(위치·딤·애니메이션·스크롤 잠금)뿐이라 기존 디자인을 덮어쓰지 않습니다.
