Layer Popup

페이지 안에 이미 있는 영역을 숨겼다가 보여주는 방식입니다. 파일을 가져오지 않습니다. 동작은 data-pop* 속성이 담당하고 생김새는 클래스가 담당하므로, 디자인이 바뀌어도 호출 코드는 그대로입니다.

Stable 최종 수정 2026-10-08 의존 popup.css · popup.js 기본 선택자 [data-pop]

01

개요

팝업 마크업을 페이지(또는 인클루드) 안에 hidden 상태로 두고, 버튼이나 스크립트가 그것을 엽니다. 서버에서 파일을 받아오지 않으므로 네트워크 지연도, 로딩 상태도 없습니다.

최소 구성 [data-pop-open] + [data-pop]
버튼과 팝업을 이름으로 연결 
<!-- 여는 버튼 -->
<button type="button" data-pop-open="g-basic">장바구니 열기</button>

<!-- 팝업 영역 : 페이지 어디에 작성해도 된다 -->
<div class="layerpopup lp" data-pop="g-basic" hidden>
  <div class="lp__panel" data-pop-panel>
    <div class="lp__head">
      <h2 class="lp__title" data-pop-label>장바구니</h2>
    </div>
    <div class="lp__body">내용</div>
    <div class="lp__foot">
      <button type="button" class="btn" data-pop-close>닫기</button>
    </div>
  </div>
</div>

data-pop-open의 값과 data-pop의 값이 같으면 연결됩니다. id를 쓰지 않는 이유는 한 페이지에 중복될 수 있고, 클래스처럼 스타일과 얽히기 쉬워서입니다.

마크업을 어디에 써도 됩니다. 매니저는 팝업을 열 때 원래 자리에 표식을 남기고 요소를 <body> 끝으로 옮긴 뒤, 닫을 때 제자리로 되돌립니다. 조상에 transform이나 overflow: hidden이 있어도 레이어가 잘리거나 갇히지 않습니다. 관련 마크업 옆에 편하게 작성하세요.
02

해부

팝업 한 개를 구성하는 속성과 각자의 역할입니다. 필수는 두 개(data-pop, data-pop-panel)뿐이고 나머지는 선택입니다.

속성 위치 필수 역할
data-pop 팝업 최상위 필수 팝업의 이름. 이 값으로 찾아서 엽니다.
data-pop-panel 팝업 안 박스 필수 실제 내용 박스. 딤 클릭 판정과 포커스 트랩의 기준이 됩니다.
hidden 팝업 최상위 권장 CSS가 로드되기 전에 내용이 번쩍이는 것을 막습니다.
data-pop-label 제목 요소 권장 스크린리더가 읽을 팝업 제목으로 연결됩니다.
data-pop-close 닫기 버튼 선택 누르면 닫습니다. 값으로 다른 팝업 이름을 줄 수도 있습니다.
data-pop-open 여는 버튼 선택 누르면 해당 이름의 팝업을 엽니다.
03

마크업으로 호출 (선언형)

기본 방식입니다. 스크립트를 한 줄도 쓰지 않습니다. 옵션은 여는 버튼에 붙여 그 호출에서만 덮어쓸 수 있습니다.

버튼 · 링크 · 팝업 안의 버튼 data-pop-open
버튼 링크 폴백 JS 꺼지면 이동 이 호출만 sm 누른 곳에서 자람 
<!-- 기본 -->
<button type="button" data-pop-open="g-basic">기본</button>

<!-- 링크로 두면 JS가 동작하지 않는 환경에서 해당 페이지로 이동한다 -->
<a href="/popup/shopping/cart.html" data-pop-open="g-basic">링크 폴백</a>

<!-- 이 호출에서만 옵션 덮어쓰기 -->
<button type="button" data-pop-open="g-basic" data-pop-size="sm">작게</button>
<button type="button" data-pop-open="g-basic" data-pop-origin="trigger">클릭 위치에서</button>


<!-- 닫기 : 값 없이 쓰면 자기가 속한 팝업을 닫는다 -->
<button type="button" data-pop-close>닫기</button>

<!-- 다른 팝업을 지목해 닫기 -->
<button type="button" data-pop-close="g-nest1">1차까지 닫기</button>

이벤트는 document에 한 번만 위임되어 있습니다. 그래서 GNB·LNB가 인클루드로 나중에 주입되어도 추가 바인딩 없이 그대로 동작합니다.

04

함수로 호출

조건에 따라 띄워야 할 때, 또는 통신 결과에 따라 띄워야 할 때 씁니다. 버튼 없이도 열 수 있습니다.

Popup API Popup.open / close / toggle / isOpen / closeAll
옵션과 함께 열기 열렸으면 닫기 버튼 없이 호출 
// 조건부 호출
if (isFirstLogin) {
  Popup.open("login/consent");
}

// 옵션과 함께 (마크업 선언을 이 호출에서만 덮어쓴다)
Popup.open("g-basic", {
  dim: "static",   // 딤 클릭으로 닫히지 않게
  size: "lg",
  origin: "center"
});

// 열림 여부 확인 후 토글
if (!Popup.isOpen("g-basic")) {
  Popup.open("g-basic");
}
Popup.toggle("g-basic");

// 닫기 : 이름을 주거나, 생략하면 최상단 팝업
Popup.close("g-basic");
Popup.close();
Popup.closeAll();

// 통신 결과에 따라
fetch("/api/notice").then(function (res) {
  return res.json();
}).then(function (data) {
  if (data.hasNotice) Popup.open("main/notice");
});
함수 인수 반환 설명
Popup.open(name, options) 이름, 옵션 선택 팝업 요소 이미 열려 있으면 아무 일도 하지 않습니다.
Popup.close(name, result) 이름 생략 가능, 결과값 선택 팝업 요소 이름을 생략하면 최상단 팝업을 닫습니다.
Popup.toggle(name, options) 이름, 옵션 선택 팝업 요소 열려 있으면 닫고, 닫혀 있으면 엽니다.
Popup.isOpen(name) 이름 true / false 현재 열려 있는지 확인합니다.
Popup.closeAll(result) 결과값 선택 없음 중첩된 것까지 전부 닫습니다.
05

결과 주고받기

확인·취소처럼 사용자의 선택을 받아야 할 때 씁니다. 전역 변수에 담아 두는 방식 대신 닫을 때 값을 실어 보냅니다.

확인 · 취소 pop:open / pop:close

아직 선택하지 않았습니다.

// 1. 팝업 안의 버튼이 결과를 실어 닫는다
document.getElementById("yes").addEventListener("click", function () {
  Popup.close("g-confirm", { confirmed: true });
});
document.getElementById("no").addEventListener("click", function () {
  Popup.close("g-confirm", { confirmed: false });
});

// 2. 부른 쪽에서 결과를 받는다 (이벤트는 버블링된다)
document.addEventListener("pop:close", function (e) {
  if (e.target.dataset.pop !== "g-confirm") return;
  if (e.detail &amp;&amp; e.detail.confirmed) {
    cancelOrder();
  }
});

// 열릴 때 초기화가 필요하면
document.addEventListener("pop:open", function (e) {
  if (e.target.dataset.pop !== "g-confirm") return;
  resetForm(e.target);
});

pop:close는 닫힘 애니메이션을 기다리지 않고 즉시 발생합니다. 후속 처리가 200ms 늦게 시작되는 일이 없습니다.

06

딤 3종

딤은 별도 요소가 아니라 레이어의 ::before 가상요소입니다. DOM이 늘지 않고, data-pop-dim 값만으로 생성 여부가 결정됩니다.

딤 모드 data-pop-dim="true | false | static"
기본 · 딤 클릭으로 닫힘 딤 없음 · 뒤 페이지 사용 가능 딤 있음 · 클릭해도 안 닫힘 
<!-- 기본값이므로 생략해도 true -->
<div class="layerpopup lp" data-pop="cart" data-pop-dim="true" hidden>…</div>

<!-- 딤 없음. 레이어가 투명 클릭 차단막으로 남지 않도록
     pointer-events 를 통과시키므로 뒤 페이지를 계속 쓸 수 있다 -->
<div class="layerpopup lp" data-pop="notice" data-pop-dim="false" hidden>…</div>

<!-- 필수 동의처럼 반드시 선택해야 하는 팝업 -->
<div class="layerpopup lp" data-pop="consent" data-pop-dim="static" hidden>…</div>

<!-- Esc 로도 닫히지 않게 하려면 -->
<div class="layerpopup lp" data-pop="consent" data-pop-dim="static" data-pop-esc="false" hidden>…</div>
딤 클릭 판정은 드래그를 보호합니다. 패널 안에서 텍스트를 드래그하다 딤에서 마우스를 떼도 닫히지 않습니다. 누른 지점과 뗀 지점을 모두 확인하기 때문입니다. click 하나만 보는 구현은 이 순간 닫혀서 작성 중이던 내용이 사라집니다.
07

유형 3종

전체화면(full)도 레이어입니다. 호스트 페이지가 뒤에 그대로 남아 있으므로 닫으면 즉시 복귀하고 입력 중이던 폼 상태도 보존됩니다. 페이지를 이동해야 하는 경우는 매니저를 쓰지 않고 그냥 링크입니다.

layer · full · 독립페이지 data-pop-type="layer | full"
기본 · 중앙 박스 뷰포트 전체를 덮는 레이어 독립페이지 그냥 이동 · 매니저 미사용 
<!-- 일반 레이어 (기본값) -->
<div class="layerpopup lp" data-pop="cart" hidden>…</div>

<!-- 전체화면 레이어 : 높이는 100dvh, 노치는 safe-area 로 피한다 -->
<div class="layerpopup lp" data-pop="terms" data-pop-type="full" hidden>…</div>

<!-- 독립페이지 : 북마크·공유·네이티브 웹뷰 대상이면 그냥 링크로 둔다 -->
<a href="/html/login/최초배정동의.html">약관 전문 보기</a>
유형 DOM 닫은 뒤 이럴 때 씁니다
layer 기본 호스트에 주입 즉시 복귀 대부분의 경우
full 호스트에 주입 즉시 복귀 · 폼 상태 보존 약관 전문, 긴 폼, 모바일 전체화면
독립페이지 주입 없음 이동 뒤로가기 필요 URL 공유·북마크·네이티브 웹뷰
08

사이드 패널 (드로어)

햄버거 메뉴처럼 화면 옆에서 나오는 패널입니다. data-pop-type="drawer"에 방향(data-pop-side)과 나오는 방식(data-pop-drawer)을 정합니다. 여는 법·닫는 법·Esc·포커스는 일반 팝업과 같습니다.

방향 · 플로팅 data-pop-side · data-pop-drawer
overlay · 기본 overlay 가장자리에서 떨어짐 
<!-- 햄버거 버튼 : 열림 상태가 aria-expanded 로 자동 반영된다 -->
<button type="button" data-pop-open="gnb-menu" aria-expanded="false" aria-label="메뉴">…</button>

<div class="layerpopup" data-pop="gnb-menu"
     data-pop-type="drawer"
     data-pop-side="left"
     data-pop-drawer="overlay" hidden>
  <nav class="lp__panel" data-pop-panel aria-label="사이트 메뉴">…</nav>
</div>

<!-- 오른쪽 / 플로팅 -->
<div … data-pop-type="drawer" data-pop-side="right" hidden>…</div>
<div … data-pop-type="drawer" data-pop-drawer="float" hidden>…</div>

패널 폭은 --pop-drawer-w(기본 320px, 최대 화면의 85%)로 바꿉니다.

본문 밀어내기 data-pop-drawer="push | squeeze" + data-pop-push-target
검증 하네스 10번에서 보기 본문을 미는 동작은 페이지 구조가 필요해 데모에서 확인 
<!-- 1. 밀려날 본문을 감싸는 요소에 표시한다. body 에는 붙이지 않는다 -->
<body>
  <div class="wrap" data-pop-push-target>
    …GNB · 본문 · 푸터…
  </div>
</body>

<!-- 2. push : 본문이 패널 폭만큼 옆으로 밀려난다 -->
<div … data-pop-type="drawer" data-pop-drawer="push" hidden>…</div>

<!-- 3. squeeze : 본문 폭이 줄어 다시 배치된다 (640px 이하에서는 push로 동작) -->
<div … data-pop-type="drawer" data-pop-drawer="squeeze" hidden>…</div>
data-pop-drawer 패널 본문 딤 · 스크롤 잠금
overlay 기본 가장자리에 붙어 덮음 그대로 켬
float 가장자리에서 떨어져 떠 있음 그대로 켬
push 가장자리에 붙음 패널 폭만큼 옆으로 밀려남 끔 본문 계속 사용
squeeze 가장자리에 붙음 폭이 줄어 다시 배치 끔 본문 계속 사용
data-pop-push-target은 <body>가 아닌 감싸개에 붙입니다. 열린 팝업은 <body> 맨 끝으로 옮겨지기 때문에 body를 밀면 메뉴 패널까지 같이 밀려납니다. 감싸개가 없으면 콘솔에 경고를 남기고 overlay로 엽니다. 밀어내기 메뉴는 본문을 쓰면서 열어두는 용도라, 같은 버튼을 다시 누르면 접힙니다.
09

중첩 (2차 팝업)

팝업 안에서 또 다른 팝업을 열 수 있습니다. 특별한 설정은 없고 평소처럼 data-pop-open을 쓰면 됩니다.

쌓기 z-index 1000 + 깊이 × 10
안에서 2차를 연다 
<div class="layerpopup lp" data-pop="g-nest1" hidden>
  <div class="lp__panel" data-pop-panel>
    <div class="lp__foot">
      <button type="button" data-pop-close>닫기</button>
      <!-- 평소와 똑같다 -->
      <button type="button" data-pop-open="g-nest2">2차 열기</button>
    </div>
  </div>
</div>

Esc는 최상단 하나만 닫습니다. 아래 레이어는 inert가 걸려 눌리지 않고, 배경 스크롤은 전부 닫힌 뒤에 풀립니다.

10

옵션 레퍼런스

같은 옵션을 세 곳에 쓸 수 있고, 충돌하면 아래 순서로 이깁니다. 팝업이 자기 기본값을 들고 있게 하고, 호출부는 예외만 덮어쓰는 것이 좋습니다.

우선순위 open() 인수 > 트리거 > 팝업 영역 > 기본값 
Popup.open("cart", { size: "lg" })   ← 1순위. 이 호출에서만
<button data-pop-open="cart" data-pop-size="md">  ← 2순위. 이 버튼에서만
<div data-pop="cart" data-pop-size="sm">          ← 3순위. 이 팝업의 기본값
                                                   ← 4순위. 시스템 기본값
옵션 값 기본 설명
data-pop-type layer · full · drawer layer 중앙 박스 / 뷰포트 전체 / 옆에서 나오는 패널
data-pop-side left · right left 드로어가 나오는 방향
data-pop-drawer overlay · float · push · squeeze overlay 드로어가 나오는 방식. push·squeeze는 딤·스크롤 잠금 기본값이 꺼짐
data-pop-dim true · false · static true 딤 생성 여부와 클릭 닫기 허용
data-pop-size sm 360 · md 520 · lg 800 없음 패널 최대 너비(px). 선언했을 때만 적용되므로 기존 팝업의 자체 폭은 그대로 유지됩니다
data-pop-origin center · trigger center trigger면 누른 버튼 자리에서 커지며 나옵니다 (전체화면·시트에는 적용 안 됨)
data-pop-sheet mobile · always 없음 mobile은 640px 이하에서만, always는 항상 하단 시트
data-pop-esc true · false true Esc로 닫기 허용
data-pop-scroll true · false 딤 false면 false, 아니면 true 배경 스크롤 잠금. 딤 없는 팝업은 뒤 페이지를 쓰는 비모달이라 기본으로 잠그지 않습니다
11

모바일

같은 마크업으로 PC와 모바일을 모두 처리합니다. 별도 페이지도, 분기 스크립트도 필요하지 않습니다.

바텀시트 전환 data-pop-sheet="mobile"
창을 640px 이하로 줄여 보세요 
<!-- 640px 이하에서 아래에서 올라오는 시트가 된다 -->
<div class="layerpopup lp" data-pop="filter" data-pop-sheet="mobile" hidden>…</div>
  • 높이는 100dvh. 100vh를 쓰면 모바일 주소창 높이만큼 아래가 잘립니다.
  • 스크롤 잠금은 위치까지 복원합니다. overflow: hidden만으로는 iOS Safari에서 잠기지 않고, 닫을 때 맨 위로 튑니다.
  • 노치·홈 인디케이터는 env(safe-area-inset-*)로 피합니다. 전체화면 팝업의 닫기 버튼이 가려지지 않습니다.
  • 팝업 끝에서 배경으로 스크롤이 넘어가지 않습니다. overscroll-behavior: contain으로 차단합니다.
12

접근성

대부분 자동으로 처리됩니다. 마크업에서 해 줄 일은 제목에 data-pop-label을 붙이는 것 하나입니다.

키보드만으로 사용해 보기 role="dialog" · aria-modal · 포커스 트랩
Tab · Shift+Tab · Esc 
<div class="layerpopup lp" data-pop="shipping" hidden>
  <div class="lp__panel" data-pop-panel>
    <!-- 이 제목이 aria-labelledby 로 자동 연결된다 -->
    <h2 class="lp__title" data-pop-label>배송 정보 입력</h2>

    <!-- 아이콘 전용 버튼에는 aria-label 을 꼭 넣는다 -->
    <button type="button" class="lp__x" data-pop-close aria-label="닫기">…</button>
  </div>
</div>
  • 열면 첫 입력 요소로 포커스가 이동하고, Tab은 팝업 안에서만 순환합니다.
  • 닫으면 원래 눌렀던 버튼으로 포커스가 돌아갑니다. 함수로 열었을 때도 직전 포커스를 기억합니다.
  • 딤이 없는 팝업은 비모달입니다. aria-modal="false"로 알리고, Tab을 가두지 않으며, 배경 스크롤도 잠그지 않습니다.
  • prefers-reduced-motion을 존중합니다. 모션을 끈 사용자에게는 애니메이션 없이 즉시 열립니다.
13

레거시 전환

한 번에 다 바꾸지 않습니다. 기존 공통 함수를 얇은 어댑터로 남겨 두면 아직 손대지 않은 페이지도 새 시스템으로 동작합니다.

인라인 핸들러 → 선언형 onclick → data-pop-open 
// 레거시 공통 함수를 이렇게만 바꿔 두면
// 호출부를 아직 수정하지 않은 페이지도 새 시스템으로 동작한다
function openPop(id) { Popup.open(id); }
function closePop(id) { Popup.close(id); }
<!-- 전 -->
<a href="javascript:void(0)" onclick="openPop('cart'); return false;">장바구니</a>
<div id="cart" style="display:none">…</div>

<!-- 후 -->
<button type="button" data-pop-open="cart">장바구니</button>
<div class="layerpopup lp" data-pop="cart" hidden>
  <div class="lp__panel" data-pop-panel>…</div>
</div>
단계 작업 영향
0 popup.css · popup.js 공통 인클루드에 1회 추가 기존 동작 변화 없음
1 팝업 마크업에 data-pop · data-pop-panel · hidden 부여 낮음
2 인라인 onclick을 data-pop-open으로 치환 낮음 기계적 · grep 가능
3 호출부가 0건이 된 레거시 함수 제거 grep 확인 후
14

사용 규칙

코드가 동작하는 것과 올바른 것은 다릅니다. 아래 두 쌍은 실제로 민원이 들어오는 지점들입니다.

권장

팝업 기본값은 팝업 영역 자신이 들고 있습니다. 어디서 열어도 모양이 같고, 디자인을 바꿀 때 한 곳만 고치면 됩니다.

지양

호출하는 버튼마다 size·dim을 전부 지정하면, 같은 팝업이 화면마다 다르게 보이고 수정할 때 모든 호출부를 찾아야 합니다.

  • 되돌릴 수 없는 동작은 data-pop-dim="static". 딤을 잘못 눌러 닫히면 사용자는 자기가 무엇을 취소했는지 모릅니다.
  • 동작은 <button type="button">. <a href="javascript:void(0)">는 키보드·스크린리더에서 링크로 읽히고 주소창에 흔적을 남깁니다.
  • 중첩은 2단까지. 3단 이상 쌓이면 사용자가 어디로 돌아가는지 알 수 없습니다. 단계가 필요하면 한 팝업 안에서 화면을 바꾸세요.
  • 팝업 이름은 도메인을 붙여 씁니다. cart보다 shopping/cart가 좋습니다. 팝업이 수백 개가 되면 짧은 이름은 반드시 충돌합니다.
